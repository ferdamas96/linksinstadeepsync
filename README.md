# Hub de links — The Deep Sync

Página única (`index.html`), sem dependências externas, pronta pra GitHub Pages.
Identidade visual do canal: **Inverno Brilhante / "Deep"** — dark mode petróleo
profundo, acentos teal-glacial e cobalto, prata como assinatura (nunca ouro).

Link de bio do Instagram **@thedeepsync.pt**.

## Conteúdo
- **Assista:** YouTube (@TheDeepSync-PT) + Instagram do canal
- **Quem apresenta:** link para a página pessoal/acadêmica da Fernanda
- **Ponte MAA / MetaScouts:** cartão pronto, porém **comentado/desligado** no
  `index.html` (é promo/afiliado). Para ligar, descomente o bloco marcado.

## ✅ Antes de publicar
1. (Opcional) Trocar o ícone de onda por um **logo**: coloque `logo.png` nesta pasta
   e siga o comentário no CSS (`.avatar`).

## 🚀 Publicar no GitHub Pages
1. Repositório **público** sugerido: `linksinstadeepsync`.
2. Subir o `index.html` na raiz.
3. Settings → Pages → Deploy from a branch → `main` / `/(root)` → Save.
4. URL: `https://ferdamas96.github.io/linksinstadeepsync/`

## ✏️ Editar depois
Cada bloco `<li>...</li>` é um botão: copie um inteiro e troque `href`, título (`.t`)
e descrição (`.s`).
